# helmet_v2 — 로컬 웹캠 테스트 평가

`models/helmet_v2_best.pt` 를 웹캠 실시간 추론(`main.py`, CONF 0.5, CPU)으로 근접 조건에서 확인.

> 테스트에 사용한 캡처 이미지는 인물 얼굴이 포함되어 저장/학습/활용하지 않음. 아래는 관찰 기록만.

## 테스트 시나리오와 결과

| # | 상황 | 검출 결과 | 판정 |
|---|---|---|---|
| 1 | 투명 페이스실드로 얼굴 가림 (근거리) | 앞사람 미검출, 원거리 동료만 `no_helmet 0.74` | 가림에 취약 |
| 2 | 맨얼굴 정면 (안경 착용) | `no_helmet 0.89` + 원거리 인물 `no_helmet 0.71` | 정확 |
| 3 | 맨얼굴, 고개 돌림 | `no_helmet 0.86` + 원거리 `no_helmet 0.71` | 정확 |
| 4 | 안전모 착용 (흰색, RT 로고) | `helmet 0.85` | 정확 |
| 5 | 안전모를 손에 들고 있음 + 맨얼굴 | 얼굴 `no_helmet 0.78`, 손의 헬멧 `helmet 0.81` | 아래 한계 참고 |

## 잘 되는 것

- 착용/미착용 구분 정확 (5장 모두), confidence 0.71~0.89로 안정적
- 근거리 + 원거리 인물 동시 검출
- 안경 착용, 학습 데이터에 없던 헬멧 디자인(RT 로고)에도 영향 없음
- helmet_v2 모델의 핵심 기능(보호구 착용 판정)이 웹캠 근접 조건에서 작동 확인됨

## 한계 (다음 단계 설계에 반영)

### 1. "helmet 검출 = 착용"이 아니다

시나리오 5에서 손에 든 헬멧이 `helmet`로 검출됨. 객체 검출로는 정답이지만 SOP 판정에서는
**머리에 착용했는가**가 기준이다. "화면에 helmet 박스가 있으면 착용"으로 처리하면 안 된다.

→ 규칙 단계에서 **person/head 박스와 helmet 박스의 위치 관계**(IoU, 머리 상단 겹침 등)로
실제 착용 여부를 판정해야 한다. 이번 테스트의 가장 큰 수확.

### 2. 가림(occlusion)에 취약

시나리오 1에서 얼굴이 가려지자 인물 자체가 미검출. 현장에서 작업 자세로 얼굴이 안 보이는
구간이 많을 것 → 그 구간은 "위반 없음"이 아니라 **판정 보류**로 처리해야 한다
(기획안 5.2절 원칙과 동일).

### 3. 웹캠 근접 조건

현재 얼굴이 화면의 30~50%를 차지. 실제 감시단원 바디캠은 2~4m 거리(기획안 그림 2 기준
안전모 약 22~35px)이므로, 이 소형 객체 조건에서의 성능은 미검증. 1주차 현장 실측 대상.

## 결론

- helmet_v2 모델 자체는 **PoC 수준 통과** — 착용/미착용을 신뢰도 있게 구분.
- 다음 단계(인원 수 검출 + 추적)에서 person/head 검출과 결합해 **공간 관계 기반 착용 판정
  규칙**을 만들어야 한다.
- 원거리·가림 조건은 현장 실측으로 검증.
