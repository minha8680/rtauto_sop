# glove_v1 — 장갑 착용/미착용 2클래스 학습 결과 (베이스라인)

세정기 작업에 쓰일 실제 장갑·공구 영상이 아직 없어(현장 미방문), 공개 데이터셋으로 먼저
베이스라인을 잡아둔 결과. **담당 카메라는 작업자 바디캠(0.8m 이내)** — 감시단원 채널
(`webcam_sop.py`)에는 통합하지 않는다(카메라 2채널 표 참고). 작업자 채널 처리기가 아직
없어 이 결과는 모델 자산으로만 우선 확보해 둔다.

## 학습 설정

| 항목 | 값 |
|---|---|
| 환경 | Google Colab GPU (T4) |
| 모델 | `yolov8n.pt` fine-tuning (glasses_v3와 달리 warm start 아님 — 첫 학습) |
| 데이터셋 | Roboflow [`safety-gloves-xbnf8`](https://universe.roboflow.com/roboflow-universe-projects/safety-gloves-xbnf8) v5 (10,459장) |
| 클래스 | 2개: `Gloves`(착용), `NO-Gloves`(미착용) — 원본부터 2클래스라 재매핑 불필요 |
| epochs | 50 |
| 체크포인트 | glasses_v2/v3와 동일한 구조 — `save_period=10` + Google Drive 직접 저장(`project=`) + `resume=True` 자동 이어학습 |

## 학습 곡선 (results.png)

- train/val loss 모두 정상 하락 후 안정화, **과적합 징후 없음**
- mAP50은 epoch ~20에서 0.93 근처에 도달한 뒤 안정적으로 유지
- precision/recall 곡선이 epoch 0~5 구간에서 크게 출렁이지만(웜업 구간, learning rate가
  아직 안정화되기 전) 이후로는 매끄럽게 수렴 — helmet_v2/glasses_v2와 같은 패턴

## helmet·glasses 대비 상대적 위치

| 모델 | mAP50 | 비고 |
|---|---|---|
| helmet_v2 | 0.96 | |
| glasses_v3 | 0.974 | |
| **glove_v1** | **0.933** | 셋 중 가장 낮지만 여전히 준수한 수준 |

- 세 모델 모두 표준 YOLOv8n fine-tuning, 클래스 수(2개)도 동일한데 glove_v1이 상대적으로
  낮은 것은 **장갑을 낀 손이 헬멧·고글보다 형태 변화가 훨씬 크기 때문**으로 추정(손 각도,
  쥐는 자세, 다른 물체에 의한 가림). 판정 대상의 형태가 고정적일수록(헬멧·고글) mAP50이
  높고, 형태가 가변적일수록(손·장갑) 낮아지는 경향은 공개 연구에서도 일반적으로 보고됨.
- 여전히 **실물 검증은 하지 않은 상태** — glasses_v1이 mAP50 0.97에도 실물에서 완전히
  실패했던 전례가 있으므로, 이 수치만으로 "잘 됐다"고 단정하지 않는다(공개 데이터 도메인과
  세정기 현장 도메인이 다를 수 있음).

## webcam_sop.py 반영 여부

**통합하지 않음.** 장갑·공구는 작업자 바디캠(근접, 0.8m 이내) 담당 항목이고
`webcam_sop.py`는 감시단원 채널 처리기다(카메라 2채널 표 참고). 작업자 채널 처리기가
생기기 전까지는 이 가중치를 그대로 보관만 한다. 로컬 웹캠 단독 검증용 스크립트는
`webcam_glove.py` 참고.

## 실물 검증 — 완전 실패 (2026-09-18~21)

우려가 현실로 확인됐다. 화학물질 취급용 안전장갑(내화학장갑) 실물 사진 총 7장으로 검증.

**1차 — 사용자 화학장갑 실물 사진 1장** (초록/회색 이중코팅, KCs 인증마크 인페인팅으로 제거
후 테스트): 0/90/180/270도 회전 전부 conf=0.15에서 미검출. conf=0.01까지 낮춰도 최고
0.098(180도) — glasses_v1이 conf 0.01까지 낮춰도 0건이었던 실패와 같은 등급.

**2차 — 화학장갑 제품 사진 6장 일괄 테스트**(웹 검색으로 수집, 같은 방식으로 회전 4종 ×
conf 0.15/0.01):

| # | 이미지 | 최고 결과 | 판정 |
|---|---|---|---|
| 1 | 내화학장갑(초록/회색) | 0.098 | 미검출 |
| 2 | EC30F 남색 화학장갑 | 0.057 | 미검출 |
| 3 | Chemtrol 파란 긴 장갑 | 0건(conf 0.01까지도) | 완전 미검출 |
| 4 | 작업자 착용 회색 장갑(실사용 장면) | 0.27 "NO-Gloves" | **오탐** — 실제 장갑은 못 잡고 방호복 후드를 "미착용"으로 표시 |
| 5 | 청록 니트릴 장갑 | 0.51 "Gloves" | 정탐, 단 90°/270°로 돌렸을 때만(원본 방향에서는 미검출) |
| 6 | 초록 장갑 착용(방호복+마스크 장면) | 0.46 "NO-Gloves" | **오탐** — 장갑 2개 다 놓치고 방호복 어깨를 "미착용"으로 표시 |

**결론**: 6장 중 5장 실패, 유일한 성공(5번)도 방향 의존적(회전시켜야만 잡힘). 더 심각한 건
4·6번처럼 **사람이 실제 착용한 사진에서 확신 있게(0.27~0.46) 엉뚱한 부위를 오탐**한다는
점 — `glasses_v2`가 일반 안경을 0.6 확신으로 "고글"이라 오탐했던 것과 같은 종류의 결함.
**공개 데이터셋 학습만으로는 실사용이 어려운 수준**으로 결론.

## 대체 데이터셋 조사 — 로보플로우 밖까지 확인, 마땅한 대안 없음 (2026-09-21)

실물 실패를 계기로 화학물질용 장갑에 특화된 공개 데이터셋을 찾아봤으나, **세 갈래 모두
채택 불가**로 결론.

1. **Roboflow Universe** — 검색상 "chemical gloves"/"내화학장갑" 전용 데이터셋 자체가
   없음. PPE Gloves(4,615장), Gloves Annotated Dataset(1,016장) 등 후보는 전부 범용
   작업용 장갑(면·가죽·정비용) 데이터셋 — 이미 실패한 `safety-gloves-xbnf8`와 같은 범주일
   가능성이 높아 재시도해도 같은 실패가 반복될 것으로 판단. Roboflow API 키가 이 세션에
   없어(이전 키는 로테이션 권고 후 재사용 안 함) 정식 3단계 검증 절차(인스턴스 수 조회 →
   동일 원본 확인 → 스타일 확인)는 완료 못함.
2. **SH17**(Kaggle/GitHub/Zenodo, 8,099장, Gloves 클래스 포함, 실제 산업현장 사진이라
   스타일은 유망해 보였음) — **라이선스가 CC BY-NC-SA 4.0(비상업적 전용)이라 제외**.
   이 프로젝트는 회사(알티자동화) 시범 과제의 일부라 "테스트용"이어도 NC의 비상업적 요건에
   맞다고 보기 애매하고, ShareAlike 조항상 이 데이터로 학습한 가중치가 파생물로서 같은
   라이선스를 물려받을 위험도 있음(이후 warm start로 재사용될 경우 오염이 이어짐). 지금까지
   고른 데이터셋(helmet/glasses/glove_v1 전부 CC BY 또는 CC0)과 원칙이 깨짐 — 예외를 두지
   않기로 함.
3. **Google Open Images V7 "Glove" 클래스**(클래스 218, CC BY 4.0, `ultralytics`가
   `open-images-v7.yaml`로 공식 지원) — 라이선스는 문제없지만, **직접 샘플 40장을 받아
   확인한 결과 화학장갑 스타일이 단 하나도 없었음**(전부 겨울/스키 장갑, 복싱 글러브,
   전술 장갑, 가죽 장갑, 니트 장갑 — Flickr 등 일반 생활 사진이 원본이라 산업용 화학장갑
   비중이 극히 낮은 것으로 추정). `fiftyone`으로 검증 후 패키지·샘플 데이터 전부 제거
   (설치 시 `opencv-python-headless`를 끌어와 `cv2.imshow`가 깨지고 `starlette`도
   구버전으로 내려가는 부수 문제가 있었음 — `requirements.txt` 주석에 남겨둠). 추가로
   Open Images는 "미착용" 대조 클래스가 없어 "Human hand"와 조합하는 새 판정 로직까지
   필요해서, 데이터만 바꾸는 게 아니라 설계 자체를 새로 해야 하는 더 큰 작업이었을 것.

**최종 결론**: 공개 데이터셋 경로는 여기서 닫는다. 장갑은 헬멧·고글과 달리 색상·재질·
형태가 근본적으로 다양한 대상이라 범용 공개 데이터로 커버하기 어렵고, **세정기 현장에서
실제 쓰는 장갑 영상으로 fine-tuning하는 것 외에 다른 길이 안 보인다.**
